## 🚀 Key Features

* **Architectural Hardening:** Clean Separation of Concerns (SoC) using Django 5, Nginx proxying, and secure environment configuration.
* **Semantic Schema.org Integration:** Dynamic JSON-LD structured data for `TechArticle`, `Person`, and `FAQPage`.
* **Interactive 3D Experience:** WebGL and Three.js integration for visual showcase.
* **Generative Engine Optimization (GEO):** Optimized for extraction and citation by Google AI Overviews, Perplexity AI, and ChatGPT Search.
* **Automated Telegram Integration:** Instant notifications and social signals via asynchronous Telegram bots.
* **Zero-Trust Security:** Strict CSRF protection, secure cookie flags, and parameterized query execution.

---

## 🛠️ Tech Stack

* **Backend:** Python 3, Django, Gunicorn
* **Frontend:** Modern HTML5, Responsive CSS3, JavaScript (WebGL/Three.js)
* **Web Server:** Hardened Nginx Reverse Proxy with TLS 1.3
* **Database:** SQLite (local dev) / PostgreSQL (production)

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/reza1384mor-dot/rezapython-web.git
cd rezapython-web
```

### 2. Set up Virtual Environment
```bash
python -m venv venv
# On Linux/macOS:
source venv/bin/activate
# On Windows:
venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment
```bash
cp .env.example .env
# Edit .env with your secret keys and configurations
```

### 5. Run Migrations & Start Development Server
```bash
python manage.py migrate
python manage.py runserver
```

Visit `http://127.0.0.1:8000` in your browser.
